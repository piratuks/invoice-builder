# Core Stack

- **Docker** - containerization for self‑hosting and reproducible deployments
- **Electron** - cross-platform desktop framework
- **SQLite** - lightweight, reliable embedded database
- **PostgreSQL** - optional networked database backend for multi-user/server setups
- **TypeScript** - safer, maintainable code
- **React** - UI framework
- **Redux Toolkit** - application state management
- **MUI** - styling and UI components
- **Vite** - dev server and build tooling for renderer, main, preload, and migrations
- **i18next** - translations and localization
- **exceljs** - XLSX import/export
- **@react-pdf/renderer** - PDF generation
- **Vitest** - unit and component testing
- **Playwright** - end-to-end testing
- **electron-builder** - desktop installer packaging
