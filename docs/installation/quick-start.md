# Quick Start

1. Launch the application
2. Create a new database file or open an existing one
3. Add at least:
   - a Layout
   - a Business
   - a Currency
   - a Client
   - a Bank
   - an Item
4. Create your first Invoice or Quote
5. Preview and export to PDF

For a walkthrough of each screen, continue with the [guides](../guides/index.md).
