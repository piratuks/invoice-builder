# Common Screen Patterns

The **Businesses**, **Banks**, **Presets**, **Clients**, **Categories**, **Units**, **Currencies**, **Items**, and **Style profiles** screens all manage simple master data and share the same create/read/update/delete (CRUD) behavior. They differ only in their fields, notes, and screenshots.

This page documents the shared behavior once. Each screen's own page covers only what is unique to it and links back here for the rest.

## Adding a record

Click the **Add** button at the bottom of the list to open a modal (or pane) where you can enter the record's information. Required and optional fields vary by screen - see each screen's page for details.

## Editing / deleting a record

Once records are added, select one from the list to edit it on the right side. Most list items also show the number of invoices and quotes created with that record (the quotes count is hidden if quotes are disabled in settings).

You can also:

- **Search** the list by name (or text, on some screens)
- **Delete** a record by clicking the red trash icon

## Filters

Each screen has filters to control what is displayed. By default:

- **Active**: shows all records except archived

The **archived flag** can be toggled during creation or editing. This flag only affects filtering and does not delete the record.

## Sorting

Records can be sorted by:

- Name (or text, on some screens)
- Last updated date

## Import & export

You can:

- Export records to XLSX
- Import records from XLSX
- Download a XLSX template for import

Some screens have additional notes about what import/export does or doesn't include (for example, logos, QR codes, or auto-created related records) - see the specific screen's page for those details.
